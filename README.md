AI Usage Analyzer
AI Usage Analyzer helps teams understand and optimize AI-assisted development across software
repositories.
What it does
Static analysis estimates token usage, context and cost by repository, folder, language and file
without executing scanned code. Dynamic analysis summarizes usage from supported local Claude
Code and GitHub Copilot session logs.
The Optimization Advisor combines analysis results to suggest improvements and projected
savings. Cloud recommendations use the selected Claude or GitHub Copilot provider when
available; local heuristics are clearly identified as a fallback.
Dashboards, charts and exports help review and share the results. Token, cost and performance
figures are estimates, not provider bills or guarantees.
